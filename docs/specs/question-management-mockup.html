Retire, don't delete

Active is toggled inside the editor only. Retired questions show an Inactive badge, keep their play history, and drop out of every new game. Active is the assumed default — no badge.

Needed count is live

“6 needed” = rounds × teams. Change rounds or team count and the target updates in the same setup flow.

Not enough to fill?

If a filter (or hand-picked list) yields fewer than needed, the match bar turns amber and Start Game is blocked with a hint.

Reuses existing data

Category & difficulty already live on every question row — no schema changes for selection. Only the library UI is net-new.

Colors, chips, toggles, tabs and buttons all use the Keeler semantic tokens (surface / inset / primary green / warning orange / danger). · Everything here is a static visual mock — no interactions wired.
